本文件把 PRD 的功能意图翻译成**可测试的句子**。每条 `REQ` 必须能被测试或验收；写不出来的，说明需求还没想清楚，回到 PRD 修改。

## 1. 需求记法

采用 EARS 常见句式，只保留三种：

- `WHEN <触发条件> THE SYSTEM SHALL <可观察行为>`：正常路径。
- `IF <异常/前置条件> THEN THE SYSTEM SHALL <可观察行为>`：异常路径。
- `WHILE <持续状态> THE SYSTEM SHALL <持续约束>`：状态约束。

约束：

- 一条 REQ 只描述一个可验证行为；出现"等等""尽量""友好"即不合格。
- 需求只写外部可观察行为，不写实现手段（"用剪贴板"不算需求，见 design）。
- 编号规则：`REQ-<FR 两位>.<序号>`；删除时保留空号，不复用。

## 2. 需求条目

### FR-01 全局触发

- **REQ-01.1** WHEN 用户在任意应用中按下鼠标中键且翻译已启用、未按住 Ctrl，THE SYSTEM SHALL 拦截该次按下与抬起事件并启动取词流程。
- **REQ-01.2** WHEN 取词结果为空，THE SYSTEM SHALL 显示 1.5 秒轻提示"未检测到选中的文字"，且不显示卡片、不触发目标应用的中键默认行为。
- **REQ-01.3** IF 用户按住 Ctrl 时按下中键，THEN THE SYSTEM SHALL 不拦截、不翻译，完整保留目标应用的原生行为。
- **REQ-01.4** WHEN 用户在设置中录制或清除键盘触发组合，THE SYSTEM SHALL 立即生效（无需重启），并且该组合按键不再输入到前台应用。
- **REQ-01.5** WHEN 用户在托盘菜单选择"暂停翻译"，THE SYSTEM SHALL 停止响应快捷键，且不拦截任何输入事件。
- **REQ-01.6** IF 前台进程名命中应用黑名单，THEN THE SYSTEM SHALL 放行输入并不发起取词。
- **REQ-01.7** WHEN 程序已在运行且用户再次启动，THE SYSTEM SHALL 不创建第二实例，并将已运行实例的设置窗口置前。

### FR-02 取词

- **REQ-02.1** WHEN 取词开始，THE SYSTEM SHALL 在 800ms 内返回选区文本或失败结果。
- **REQ-02.2** WHILE 取词使用模拟复制，THE SYSTEM SHALL 在取词结束后还原取词前的剪贴板内容；还原失败不得阻断翻译。
- **REQ-02.3** IF 剪贴板被其他程序占用，THEN THE SYSTEM SHALL 重试至多 3 次（间隔 50ms），仍失败则提示"剪贴板被其他程序占用"并允许重试。
- **REQ-02.4** IF 当前焦点位于密码输入框，THEN THE SYSTEM SHALL 不读取、不发送任何内容，并提示"已跳过密码输入框"。
- **REQ-02.5** IF 选区为空、仅空白或仅含图片/文件，THEN THE SYSTEM SHALL 视为未选中，不显示卡片。
- **REQ-02.6** WHEN 取词成功，THE SYSTEM SHALL 去除首尾空白与不可见字符、合并连续空行，并保留段落换行。

### FR-03 语言判定

- **REQ-03.1** WHEN 取词成功，THE SYSTEM SHALL 依据字符构成判断主导语种。
- **REQ-03.2** IF 主导语种与目标语言一致，THEN THE SYSTEM SHALL 不发起翻译请求，显示"已是目标语言"与"仍要翻译"按钮。
- **REQ-03.3** WHEN 用户点击"仍要翻译"，THE SYSTEM SHALL 跳过语种判断并发起翻译。
- **REQ-03.4** WHEN 用户更改目标语言，THE SYSTEM SHALL 在下次触发时使用新语言，无需重启。

### FR-04 翻译

- **REQ-04.1** WHEN 翻译开始，THE SYSTEM SHALL 以流式方式展示译文；服务端返回整段内容时按整段展示。
- **REQ-04.2** WHEN 用户按 Esc、关闭卡片、再次触发、暂停或退出，THE SYSTEM SHALL 立即取消在途请求。
- **REQ-04.3** IF 连接超过 10 秒或整体超过 30 秒（或用户配置值），THEN THE SYSTEM SHALL 终止请求、提示超时并提供"重试"。
- **REQ-04.4** IF 发生网络错误、5xx 或 429，THEN THE SYSTEM SHALL 自动重试 1 次（退避 1 秒）；401/403/404 不自动重试。
- **REQ-04.5** IF 文本超过 8000 字符，THEN THE SYSTEM SHALL 截断到上限并提示"文本过长，已截断"。
- **REQ-04.6** WHILE 已有请求在途，THE SYSTEM SHALL 先取消旧请求再发起新请求，只展示最新结果。

### FR-05 结果卡片

- **REQ-05.1** WHEN 卡片显示，THE SYSTEM SHALL 不改变前台窗口，用户输入继续进入原应用。
- **REQ-05.2** WHEN 卡片定位，THE SYSTEM SHALL 使其完整落在光标所在显示器的工作区内；边缘不足时自动翻转。
- **REQ-05.3** IF 用户按 Esc 或点击卡片外部（未图钉），THEN THE SYSTEM SHALL 关闭卡片。
- **REQ-05.4** WHEN 用户点击图钉，THE SYSTEM SHALL 在点击外部时保持卡片显示，直到再次点击图钉、Esc 或关闭按钮。
- **REQ-05.5** WHILE 译文增长，THE SYSTEM SHALL 保持卡片左上角位置不变、高度向下扩展；超过工作区 60% 后内容内部滚动。

### FR-06 复制译文

- **REQ-06.1** WHEN 用户点击"复制"或双击译文区，THE SYSTEM SHALL 将完整译文写入剪贴板，并显示 1.5 秒"已复制"。
- **REQ-06.2** IF 写入剪贴板失败，THEN THE SYSTEM SHALL 提示"复制失败，请重试"。

### FR-07 设置与首次向导

- **REQ-07.1** WHEN 用户修改任一设置，THE SYSTEM SHALL 立即保存并在下一次翻译生效，无需重启。
- **REQ-07.2** WHEN 用户点击"测试连接"，THE SYSTEM SHALL 发起一次最小请求并显示往返延迟或具体错误。
- **REQ-07.3** WHEN 首次运行，THE SYSTEM SHALL 显示 3 步向导（服务商与 Key → 测试连接 → 自启与试用），允许跳过。
- **REQ-07.4** IF 服务商地址为非本机的 `http://`，THEN THE SYSTEM SHALL 在设置页持续提示明文传输风险。
- **REQ-07.5** WHEN 用户把某进程加入黑名单，THE SYSTEM SHALL 在该进程处于前台时不触发翻译。
- **REQ-07.6** IF 首选配置目录不可写，THEN THE SYSTEM SHALL 依次回退到 `%LOCALAPPDATA%\SelectTranslate` 与程序目录 `data\`，并在日志中记录回退原因；若全部不可写，THE SYSTEM SHALL 显示错误提示后退出。

### FR-08 托盘常驻

- **REQ-08.1** WHEN 程序启动，THE SYSTEM SHALL 显示托盘图标，菜单包含启用翻译、打开设置、开机自启、查看日志、退出。
- **REQ-08.2** WHEN 首次向导完成且用户未取消自启，THE SYSTEM SHALL 写入开机自启项，并在下次登录时自动启动。
- **REQ-08.3** IF 启动参数为 `-portable`，THEN THE SYSTEM SHALL 将配置与日志存放在程序目录，且默认不写开机自启。
- **REQ-08.4** WHEN 用户退出，THE SYSTEM SHALL 卸载全部监听、取消在途请求并保存配置。

### FR-09 失败反馈

- **REQ-09.1** WHEN 任一失败发生，THE SYSTEM SHALL 显示中文说明与下一步动作，不显示堆栈或裸错误码。
- **REQ-09.2** WHEN 失败无需用户决策，THE SYSTEM SHALL 使用 1.5 秒自动消失的轻提示，且不抢焦点。
- **REQ-09.3** IF 前台窗口以管理员身份运行而本程序未提权，THEN THE SYSTEM SHALL 不响应且不崩溃（系统不把该窗口的输入交给低权限进程），并在托盘提供“以管理员身份重启”入口。

### FR-10 隐私与安全

- **REQ-10.1** WHEN 保存 API Key，THE SYSTEM SHALL 以当前 Windows 用户为范围加密后落盘。
- **REQ-10.2** WHILE 程序运行，THE SYSTEM SHALL 不在日志中记录原文、译文或 Key。
- **REQ-10.3** WHEN 用户未触发翻译，THE SYSTEM SHALL 不向任何服务发送文本。
- **REQ-10.4** IF 用户配置明文 HTTP 地址，THEN THE SYSTEM SHALL 在设置页显示持续警告。

### FR-11 服务商扩展

- **REQ-11.1** WHEN 展示服务商设置，THE SYSTEM SHALL 支持新增、编辑、删除多个服务商档案，并提供"服务商类型"选择；v1.0 仅 OpenAI 兼容可选，其余选项显示"即将支持"且不可选。
- **REQ-11.2** WHEN 用户把某个服务商设为当前，THE SYSTEM SHALL 在不重启的情况下让下一次翻译使用该档案。

### FR-12 分发

- **REQ-12.1** WHEN 用户在未安装任何运行环境的 Windows 11 上解压并双击程序，THE SYSTEM SHALL 直接运行，不提示缺少运行环境。
- **REQ-12.2** WHEN 生成分发包，THE SYSTEM SHALL 包含程序本体、使用说明、许可与 SHA256 校验值。

## 5. 验收环境与前置

- Windows 11 22H2 / 23H2 / 24H2，x64。
- 至少一台无开发环境的干净虚拟机（用于 AC-31）。
- 一个可用的 OpenAI 兼容服务账号，以及一个用于模拟错误的测试端点（401/429/超时）。
- 双屏不同缩放环境（用于 AC-19）。
- 管理员权限会话（用于 AC-27 的反向验证）。
