## 0. 约定

- 每个任务必须能对应到 `requirements.md` 的 REQ 与 AC；对不上的任务不开工。

- 预估为单人有效工作日，不含评审与等待。
- 完成定义（DoD）：代码合并 + 相关 AC 在本机可复现通过 + 文档同步更新。

补充记录（2026-11-05）：M1 自检时发现，从受限目录（低完整性进程）启动时首选配置目录不可写，程序会在写日志阶段抛异常并静默无托盘。已按 REQ-07.6 / AC-33 增加目录回退（`%APPDATA%` → `%LOCALAPPDATA%` → `<exe>\data`），并新增启动失败弹窗与 `startup-error.log`，不再静默失败。

人工自检步骤（开发机）：

1. 启动 `src/SelectTranslate.App/bin/Debug/net10.0-windows/SelectTranslate.exe -portable`
2. 按中键：卡片出现在光标右下；再按一次关闭
3. 按住 Ctrl 按中键：浏览器正常自动滚动，不弹卡片
4. 托盘菜单取消"启用翻译"后再按中键：无反应、页面正常滚动
5. 再次双击 exe：不出现第二个托盘图标，设置窗口置前
