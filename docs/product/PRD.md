## 0. 一页纸

**一句话**：在 Windows 任何软件里选中一段外文，按一下鼠标中键，光标旁弹出卡片，流式显示译文。

**它解决什么**：读外文时"复制 → 切翻译网站 → 粘贴 → 切回来"的四步打断，变成"选中 → 按键 → 读完 → Esc"的一步。

**它不做什么**：不做截图 OCR、不做朗读、不做离线模型、不做插件平台、不做历史记录。

**默认形态**：

| 项 | 默认 |
|---|---|
| 触发 | 鼠标中键按下（按住 Ctrl 时保留原生行为） |
| 目标语言 | 简体中文（可切换） |
| 卡片 | 宽 420，出现在光标右下，Esc 或点卡片外关闭 |
| 开机自启 | 开启，可在设置中关闭 |
| 分发 | 免安装压缩包，解压双击即用 |

**成功的样子**：用户装上后 2 分钟内完成配置，之后每次读外文都不再打开浏览器标签页。

## 1. 背景与机会

### 1.1 问题

外文阅读发生在别人的应用里：浏览器、Word、IDE、聊天窗口、PDF 阅读器。用户不想离开当前上下文，但现有翻译工具要求离开——复制、切换窗口、粘贴、再切回来。四次操作、两次上下文切换，一篇文章要重复几十次。

### 1.2 市场上的两类产品

- **截图/贴图类工具（如 Snipaste）**：常驻托盘、快捷键即用、体积小、几乎无感。用户对这类工具的期待是"按一下就出现，按一下就消失"，不能有安装负担、不能占内存。
- **工具箱类（如 uTools）**：用"超级面板"把"选中文字 → 弹出面板 → 面板里给出翻译"串起来，交互顺手；但这类工具本身较重，启动和常驻成本高。

用户真正想要的是：**uTools 超级面板的交互手感 + Snipaste 的轻量与无感**，且不需要一整套插件平台。

### 1.3 我们的机会

只做一件事：**全局划词翻译**。不做截图、不做插件、不做工作台。用最少的界面完成"选中 → 翻译 → 读完 → 关闭"，并且让用户自己决定用哪家大模型。

## 2. 目标与成功度量

| 编号 | 目标 | 如何判断达成 |
|---|---|---|
| G1 | 选中到看见卡片的等待感足够短 | 按键后 200ms 内卡片可见；服务商响应快时首字 1.5s 内出现 |
| G2 | 零安装负担 | 干净 Windows 11 电脑上解压双击即可运行，不提示缺少运行环境 |
| G3 | 不打断当前工作 | 卡片出现时前台窗口不变，用户可继续在原应用打字 |
| G4 | 配置一次，长期可用 | 首次向导 3 步完成；之后无需再打开设置 |
| G5 | 用得起、换得掉 | 用户可更换接口地址、Key、模型，不被绑定到单一服务商 |

## 3. 非目标（v1.0 硬边界）

以下需求**明确不做**，新增需重新评审：

1. 截图 / OCR 翻译（不识别图片里的文字）。
2. 语音朗读（TTS）、语音输入。
3. 离线翻译或内置模型（可连本地服务，但不内置）。
4. 翻译历史、收藏、生词本。
5. 多张卡片并列、翻译对照视图。
6. 插件体系、脚本扩展、第三方集成。
7. macOS / Linux / 移动端。
8. "划词即自动翻译"（不按键就触发）——必须显式按键。
9. 托盘"翻译剪贴板"入口（不选中、直接翻译剪贴板内容）。
10. Google 翻译、有道翻译等非 OpenAI 兼容协议的接入（v1.1 再做）。

## 4. 用户与场景

### 4.1 用户画像

| 画像 | 特征 | 最在意 |
|---|---|---|
| 开发者 | 读英文文档、报错、源码注释 | 快、不打断、能复制译文 |
| 办公用户 | 读外文邮件、说明书、聊天记录 | 简单、不用学、不弹大窗口 |
| 多语种用户 | 中日英混用，目标语言常切换 | 目标语言可改、判断准确 |

共同点：Windows 11；已有一个可用的大模型接口（公司内网或公开服务）；不愿意为一个小工具装运行环境。

### 4.2 主场景

**S1 浏览器读长文**：Chrome 中选中一段英文 → 按中键 → 卡片在光标右下出现，先显示原文，译文逐字出现 → 读完按 Esc → 页面位置不变，没有新标签页。

**S2 Word / IDE 看报错**：选中三行异常信息 → 按中键 → 译文出现 → 点"复制" → 切回编辑器粘贴。

**S3 聊天窗口读外文**：在微信或 Telegram 选中一句德语 → 按中键 → 中文译文 → 双击译文区复制。

**S4 切换目标语言**：用户把目标语言改为日语，之后选中英文按中键，得到日语译文；再改回中文立即生效。

### 4.3 失败场景（必须优雅）

| 场景 | 用户感受 |
|---|---|
| 全屏游戏、受保护窗口 | 不弹卡片，只给一句轻提示，不抢焦点、不崩溃 |
| 密码输入框 | 明确提示"已跳过密码输入框"，绝不发送内容 |
| 以管理员权限运行的窗口 | 说明原因，并告诉用户"以管理员身份运行本程序"可解决 |
| 没选中任何文字 | 提示"未检测到选中的文字"，中键不再触发浏览器滚动 |

### 4.4 用户故事

| 编号 | 故事 |
|---|---|
| US-01 | 作为读者，我选中英文段落后按中键，200ms 内看到卡片，很快开始出译文 |
| US-02 | 作为开发者，我选中报错信息，点"复制"拿到完整译文 |
| US-03 | 作为多语种用户，我把目标语言改成日语，下次触发即按日语翻译 |
| US-04 | 作为隐私敏感用户，我的 Key 是加密存的，文本只在我按键时才发出去 |
| US-05 | 作为分享者，我把压缩包发给朋友，他解压双击就能用 |

## 5. 功能需求（产品层）

### 5.1 功能地图

| ID | 功能 | 优先级 | 一句话 |
|---|---|---|---|
| FR-01 | 全局触发 | P0 | 任意应用中按中键即翻译；可改键、可暂停、Ctrl 旁路 |
| FR-02 | 取词 | P0 | 读取选中文字，且不破坏用户剪贴板 |
| FR-03 | 语言判定 | P0 | 已是目标语言就不翻译，给"仍要翻译" |
| FR-04 | 翻译 | P0 | 流式显示；可取消、超时重试、超长截断 |
| FR-05 | 结果卡片 | P0 | 光标旁浮窗，不抢焦点，关闭规则明确 |
| FR-06 | 复制译文 | P0 | 一键或双击复制完整译文 |
| FR-07 | 设置与首次向导 | P0 | 服务商、语言、外观、快捷键、黑名单、自启 |
| FR-08 | 托盘常驻 | P0 | 常驻托盘，可暂停、可退出、开机自启 |
| FR-09 | 失败反馈 | P0 | 每种失败都有中文说明和下一步动作 |
| FR-10 | 隐私与安全 | P0 | Key 加密、日志脱敏、不采集、不后台发送 |
| FR-11 | 服务商扩展 | P0 | 现在只支持 OpenAI 兼容；界面为后续服务商留位 |
| FR-12 | 分发 | P1 | 免安装压缩包；安装器/自动更新/签名后续再做 |

### 5.2 FR-01 全局触发

- 默认绑定**鼠标中键按下**（不是滚动，不是长按）。按下即触发，松开不产生副作用。
- 按住 **Ctrl** 再按中键：不翻译，保留应用原生行为（浏览器自动滚动、后台打开链接）。
- 可在设置中改绑：其他鼠标键（侧键）或键盘组合键；改绑后旧键恢复原生行为，立即生效。
- 托盘菜单可"暂停翻译"：暂停后按键完全透传，不拦截、不提示。
- 支持**应用黑名单**：列表内的应用里按键不触发、不拦截。
- 程序只允许运行一个实例；重复启动时把设置窗口带到前面。

### 5.3 FR-02 取词

- 优先读取当前应用的选区文字，读不到时退化为"模拟复制"再还原剪贴板。
- **不破坏剪贴板**：翻译结束后，用户剪贴板内容与翻译前一致（复杂格式尽力还原，失败不影响翻译）。
- 取词总耗时上限 800ms；超时视为失败，给出可重试提示。
- 只取纯文本；图片、文件、空白选区视为"没有选中"。
- 密码输入框一律拒绝，并提示"已跳过密码输入框"。
- 取词结果做清洗：去首尾空白、去不可见字符、连续空行合并；保留原有换行。

### 5.4 FR-03 语言判定

- 按字符构成判断主导语种，用于决定是否值得翻译。
- 目标语言与文本主导语种一致时，不发起翻译，卡片显示"已是简体中文"并给一个"仍要翻译"按钮。
- "仍要翻译"用于：繁体转简体、中日汉字混排、用户就是想看模型怎么译。
- 目标语言可切换：简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、俄语；自定义语言码为 P1。

### 5.5 FR-04 翻译

- 支持任意 **OpenAI 兼容**接口：用户填接口地址、Key、模型名。
- 流式显示：译文逐字出现，不必等整段完成。
- 取消：按 Esc、关闭卡片、再次触发、暂停或退出，立即中断在途请求。
- 超时：连接 10 秒、整体 30 秒（可调 10–120 秒）；超时给"重试"。
- 重试：网络错误、服务端 5xx、限流（429）自动重试 1 次；鉴权/模型不存在不重试，直接引导去设置。
- 长度：超过 8000 字符截断，并明确告知"已截断"。
- 并发：同一时刻只有一个翻译请求，新请求替换旧请求。

### 5.6 FR-05 结果卡片

- 出现在光标附近（默认右下 16px），靠近屏幕边缘时自动翻转，始终完整落在当前显示器内。
- **不抢焦点**：卡片显示时，原应用仍是前台，用户可继续打字；卡片不进入 Alt-Tab。
- 内容分四段：状态条（译自什么语言、目标语言、模型名）、原文（最多 3 行，可展开）、译文（流式）、工具条（复制、重试、图钉、设置、关闭）。
- 高度随内容增长，最高为屏幕工作区的 60%，超出后内部滚动。
- 关闭方式：Esc、点击卡片外部、再次触发、托盘暂停、退出程序。
- 图钉：固定后点击外部不关闭，直到再次点图钉、Esc 或关闭按钮。
- 同一时间只有一张卡片；新翻译替换旧卡片。

### 5.7 FR-06 复制译文

- 点"复制"或双击译文区，复制完整译文（不含原文、不含界面文字）。
- 复制成功后在卡片内显示 1.5 秒"已复制"，不弹系统通知。
- 复制失败（剪贴板被占用）提示"复制失败，请重试"。

### 5.8 FR-07 设置与首次向导

- 左侧导航：服务商 / 快捷键 / 外观 / 高级 / 关于；改动即时保存、即时生效。
- 服务商：类型（v1.0 只有 OpenAI 兼容可选，Google/有道显示"即将支持"）、预设（DeepSeek / OpenAI / OpenRouter / 本地 Ollama / 自定义）、接口地址、Key（掩码显示）、模型、温度、超时、流式开关、系统提示词、"测试连接"。
- 快捷键：主快捷键录制、备用键盘快捷键、Ctrl 旁路说明、暂停开关。
- 外观：主题（跟随系统/浅/深）、卡片宽度、字号、自动关闭秒数（0 = 不关）、动画开关。
- 高级：目标语言、应用黑名单、文本上限、日志级别、打开配置目录、导出/导入配置（P1）。
- 关于：版本号、检查更新（P2）、许可、反馈入口。
- 首次启动向导 3 步：选服务商并填 Key → 测试连接 → 确认开机自启（默认勾选）并试一次。

### 5.9 FR-08 托盘常驻

- 常驻系统托盘；右键菜单：启用翻译、打开设置、开机自启、查看日志、退出。
- 双击图标打开设置。
- 默认开机自启；可在设置和托盘菜单中关闭。便携模式下默认不写自启（避免 U 盘盘符变化）。
- 退出时卸载所有监听、取消在途请求、保存配置。

### 5.10 FR-09 失败反馈

- 每种失败都必须说明"发生了什么、下一步做什么"，禁止只报错误码或堆栈。
- 轻提示（气泡）不抢焦点，1.5 秒自动消失；需要用户决策的错误显示在卡片里。
- 失败不阻塞输入：任何错误下用户都能继续在原应用工作。

### 5.11 FR-10 隐私与安全

- Key 在本机加密存储，换 Windows 账户无法解密。
- 日志只记录时间、来源应用、文本长度、耗时、错误类型；**不记录原文与译文**。
- 只在用户按键后发送文本；不后台采集、不做遥测、不静默上传。
- 密码框拒绝取词；黑名单应用不取词。
- 用户填写非本机 `http://` 地址时，设置页持续提示"将明文传输 Key"。
- 配置只存当前用户目录，不要求管理员权限。

### 5.12 FR-11 服务商扩展

- v1.0 面向用户提供"服务商类型"选择，目前只有 OpenAI 兼容一项；Google 翻译、有道翻译显示为"即将支持"。
- v1.1 增加这两种服务商后，用户可在设置里切换类型并填写各自的凭据，交互与现在一致（不新增第二个设置页）。
- 切换服务商不需要重启程序，下一次翻译即生效。

### 5.13 FR-12 分发

- 交付物：免安装压缩包（单 exe + 说明 + 许可 + 校验值），解压双击即用。
- 说明文件包含：3 步上手、SmartScreen 处理、常见问题。
- 支持便携模式：配置与日志存在 exe 同目录，便于放 U 盘。
- 安装器、自动更新、代码签名、ARM64 版本列为 v2.0。

## 6. 关键交互

### 6.1 主流程

```
选中文字 → 按中键（未按 Ctrl）
   → 卡片出现（约 200ms 内，先显示原文与"翻译中"）
   → 译文逐字出现
   → 读完：Esc / 点卡片外 / 再次触发
```

### 6.2 卡片示意

```
┌──────────────────────────────────────────────┐
│ ● 译自 English → 简体中文          deepseek  │
├──────────────────────────────────────────────┤
│ The quick brown fox jumps over the lazy dog. │
│ It was a bright cold day in April...  [展开] │
├──────────────────────────────────────────────┤
│ 敏捷的棕色狐狸跳过了懒狗。那是四月里一个明亮  │
│ 而寒冷的日子……▌                              │
├──────────────────────────────────────────────┤
│ [复制]  [重试]  [📌]           [设置]  [ × ] │
└──────────────────────────────────────────────┘
```

### 6.3 卡片状态（用户视角）

| 状态 | 用户看到 |
|---|---|
| 取词中 | 极短（<120ms）不显示，超过则显示骨架 |
| 翻译中 | 原文 + "翻译中…" + 进度条 |
| 输出中 | 译文逐字增长，末尾有光标 |
| 完成 | 完整译文 + 可用工具条 |
| 失败 | 一句中文说明 + "重试"或"去设置" |
| 已是目标语言 | "已是简体中文" + "仍要翻译" |

### 6.4 位置与关闭

- 默认光标右下 16px；右边不够向左翻，下边不够向上翻；始终夹在当前显示器工作区内，四周留 8px。
- 多显示器、不同缩放比例下位置必须正确、文字清晰。
- Esc 关闭；点击卡片外部关闭（图钉时除外）；再次触发替换；托盘暂停立即关闭。

### 6.5 文案基调

- 短句、说人话、给动作。例："未检测到选中的文字"而不是"取词失败（E_NO_SELECTION）"。
- 不出现技术术语（"接口""流式""token"仅在设置页出现，且必须有解释）。
- 关键文案：未选中、跳过密码框、已是目标语言、文本过长、未配置、鉴权失败、限流、网络不可达、超时、需要管理员权限、已复制、复制失败。

### 6.6 设置结构

| 页面 | 内容 |
|---|---|
| 服务商 | 类型、预设、地址、Key、模型、温度、超时、流式、提示词、测试连接 |
| 快捷键 | 主键录制、备用键、Ctrl 旁路说明、暂停 |
| 外观 | 主题、宽度、字号、自动关闭、动画 |
| 高级 | 目标语言、黑名单、文本上限、日志级别、配置目录、导入导出（P1） |
| 关于 | 版本、更新（P2）、许可、反馈 |

## 7. 体验指标（用户可感知）

| 指标 | 目标 |
|---|---|
| 按键到卡片可见 | ≤200ms |
| 取词完成（不含模型） | ≤800ms |
| 冷启动 | ≤2 秒（首次解压后）；后续 ≤1 秒 |
| 常驻内存 | ≤100MB（空闲） |
| 空闲 CPU | <0.1% |
| 安装包体积 | ≤100MB |

> 模型响应速度取决于用户选择的服务商，不在承诺范围内；程序只保证本地不额外增加等待。
