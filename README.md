# SelectTranslate（划词译）

在任意 Windows 软件里选中一段外文，按一下鼠标中键（或自定义快捷键），光标旁弹出卡片并显示译文。翻译请求走你自己配置的 OpenAI 兼容接口，不绑定服务商。

- **全局生效**：浏览器、Office、PDF 阅读器、IDE、聊天工具都能用
- **不抢焦点**：卡片出现时你还能继续在原窗口输入
- **免安装**：解压即用，自带 .NET 运行时，不用另外装环境
- **可替换**：接口地址、Key、模型、目标语言、触发热键都在设置里改

## 快速开始

1. 解压 `SelectTranslate-v0.9.0-win-x64.zip` 到任意目录（**不要放在需要管理员权限才能写的目录**）
2. 双击 `SelectTranslate.exe`；Windows 可能会弹 SmartScreen 提示，选"更多信息 → 仍要运行"
3. 托盘区出现图标（Win11 默认收在 `^` 溢出区里）
4. 右键托盘图标 → **打开设置**：
   - 在「翻译服务商」里填写：**名称**（自定义，例如"DeepSeek 官方"）、**接口地址**（如 `https://api.deepseek.com/v1`）、**API Key**、**模型**（如 `deepseek-chat`）
   - **目标语言**：默认简体中文
   - 点 **测试连接**，显示"连接正常，xxx ms"后点 **保存**
   - 需要多个服务商时点 **新增** 再填一套；在列表里选中后点 **设为当前**，**下一次翻译立即切换**（列表里 ● 表示当前）
5. 在任意应用里选中外文 → 按鼠标中键（或你在"触发热键"里录制的组合键）→ 卡片出现

## 系统要求

- Windows 11 x64（Windows 10 21H2+ 理论可用，未完整验证）
- 约 200MB 磁盘空间（自包含运行时）
- 可访问你配置的模型接口

## 使用

| 操作 | 效果 |
|---|---|
| 中键 / 自定义热键 | 取词并翻译；再次触发会在新位置重开 |
| 点击卡片外部 | 关闭卡片 |
| Esc | 关闭卡片（钉住时也关闭） |
| 卡片右上角 📌 | 钉住：点外部不再关闭；钉住后**拖动卡片顶部一条**可移动卡片 |
| 卡片右上角 ✕ | 关闭卡片 |
| 「复制」或双击译文 | 复制完整译文，状态显示"已复制" |
| 「重试」 | 重新请求；模型原样返回时会提示 |
| 「仍要翻译」 | 原文已是目标语言时，强制翻译 |

托盘菜单：启用/暂停翻译、打开设置、**以管理员身份重启**、开机自启、查看日志、退出。

### 键盘热键

设置 → 触发热键 → 点输入框后直接按组合键（如 `Ctrl+Alt+T`，必须含 Ctrl/Alt/Shift/Win 之一）→ 保存。热键会**吞掉该组合**，不会输入到前台应用；点「清除」恢复只用鼠标中键。

### 管理员窗口

标准权限下，任务管理器、管理员终端等**提权窗口的输入收不到**（Windows UIPI 限制），按中键不会有反应。需要翻译这类窗口时：托盘右键 → **以管理员身份重启** → 同意 UAC。

## 隐私

- API Key 用 Windows DPAPI 加密后保存在 `%APPDATA%\SelectTranslate\config.json`，只有当前 Windows 用户能解密
- 日志（`%APPDATA%\SelectTranslate\logs\`）只记录字数、耗时、模型名、错误类型，**不记录原文、译文与 Key**
- 除了你配置的接口，程序不向任何其他地址发送数据

## 已知限制

- 当前版本**非流式**：译文会等模型整段返回后一次性出现（流式在 v1.0 计划中）
- 部分自绘控件、DirectX 独占全屏、Java/UWP 应用可能取不到选区
- 剪贴板兜底取词目前只备份/还原文本，选中有图片/富文本的内容时可能丢失原格式
- 不支持 ARM64；无安装器、无自动更新、无代码签名（SmartScreen 会提示）

## 常见问题

**按中键没反应？**
1. 托盘菜单确认"启用翻译"是勾选状态；
2. 前台窗口是不是管理员程序（见上文）；
3. 右下角托盘图标是否在 `^` 溢出区里，程序是否还在运行；
4. 换键盘热键试一次；仍不行请看 `%APPDATA%\SelectTranslate\logs\` 最新日志。

**测试连接很快，但翻译很慢？**
多半是该模型默认带"思考/reasoning"，翻译不需要。在设置 → 该服务商 → **深度思考** 选「否」并保存即可；程序会按模型名自动选择正确的字段：

| 模型名前缀 | 关闭时写入 |
|---|---|
| doubao / deepseek / glm / kimi | `thinking.type = disabled` |
| qwen | `enable_thinking = false` |
| gpt / o1 / o3 / o4 | `reasoning_effort = minimal`（无法完全关闭） |
| 其他 | 不写字段；可用「附加请求参数」手动指定 |

数值以服务商文档为准；「附加请求参数」里的内容优先级最高，可随时覆盖自动推断。

**卡片位置不对 / 跑到副屏？**
把光标放在目标位置再触发即可；多屏不同缩放比例已处理，但极窄工作区仍可能贴边。

**开机自启**：默认开启。便携使用或不想自启，在托盘菜单里取消"开机自启"。
